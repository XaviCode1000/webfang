1//! HTTP client wrapper with retry middleware and status-specific handling
2//!
3//! Provides a configurable HTTP client with:
4//! - Custom headers (Accept-Language, Accept, Referer, Cache-Control)
5//! - Exponential backoff retry policy
6//! - Specific handling for 403 (rotate UA), 429 (backoff), 5xx (retry)
7//! - Cookie support
8//! - Configurable request and connection timeouts
9//! - Rate limiting (requests per minute)
10//! - URL validation
11//! - TLS fingerprint rotation (Chrome 131, 145, Firefox, etc.)
12//!
13//! # Architecture
14//!
15//! The port contract (`HttpClientPort`, `HttpResponse`, `HttpError`,
16//! `HttpResult`, `HttpClientConfig`) is **owned by the domain layer**
17//! (`crate::domain::http_port` / `http_error` / `http_config`). This
18//! module re-exports them for backward compatibility so existing importers
19//! (`crate::application::http_client::*`) keep working. The concrete
20//! `HttpClient` and the `impl HttpClientPort for wreq::Client` live here,
21//! depending inward on the domain port (Clean Architecture direction).
22//!
23//! # Examples
24//!
25//! ```no_run
26//! use webfang_core::application::http_client::{HttpClient, HttpClientConfig};
27//! use wreq_util::Profile;
28//!
29//! let config = HttpClientConfig {
30//!     timeout_secs: 60,
31//!     rate_limit_rpm: Some(30),
32//!     tls_emulation: Profile::Chrome131,
33//!     ..Default::default()
34//! };
35//! let client = HttpClient::new(config).unwrap();
36//! // Use client for HTTP requests
37//! ```
