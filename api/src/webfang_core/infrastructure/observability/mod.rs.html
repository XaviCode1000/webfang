1//! Observability Module
2//!
3//! Production-grade observability infrastructure:
4//! - Structured JSON logging with file rotation
5//! - FileTraceLayer: JSONL span/event traces for offline debugging
6//! - Tokio console for runtime debugging
7//!
8//! # Tokio Console (Optional)
9//!
10//! For runtime observability, enable the `console` feature:
11//! ```bash
12//! RUSTFLAGS="--cfg tokio_unstable" cargo run --features console -- --url ...
13//! ```
14//!
15//! Then in your code:
16//! ```ignore
17//! #[cfg(feature = "console")]
18//! webfang_core::infrastructure::observability::init_console();
19//! ```
20

25/// Initialize tokio-console for runtime debugging
26///
27/// # Requires
28/// - RUSTFLAGS="--cfg tokio_unstable" at compile time
29/// - Feature flag `console` enabled
30///
31/// # Note
32/// Only available when compiled with `console` feature.
33/// Without the feature, this function is a no-op.
34#[cfg(feature = "console")]
35pub fn init_console() {
36    console_subscriber::init();
37}
