1//! AI module — Full RAG Pipeline Integration (Phase 2 + Phase 3)
2//!
3//! This module provides AI-powered semantic cleaning capabilities with full pipeline integration:
4//! - Model resolution via hf_hub native cache (cache-first offline via `hf_hub::Cache`,
5//!   `ApiRepo` online, with in-memory SHA256 validation)
6//! - Memory-mapped model loading (zero-copy for HDD optimization)
7//! - ONNX inference for embedding generation (Phase 2)
8//! - Semantic chunking with arena allocator (Phase 3)
9//! - SIMD-accelerated cosine similarity filtering (Phase 3)
10//!
11//! # Architecture
12//!
13//! Following Clean Architecture, this module implements the [`SemanticCleaner`](crate::SemanticCleaner)
14//! trait defined in the domain layer.
15//!
16//! ```text
17//! HTML Input
18//!     ↓
19//! [Chunker] Split into semantic chunks (arena allocator)
20//!     ↓
21//! [Tokenizer] Convert each chunk to token IDs
22//!     ↓
23//! [InferencePool] Generate embeddings (dedicated worker threads)
24//!     ↓
25//! [RelevanceScorer] Filter by threshold (SIMD cosine similarity)
26//!     ↓
27//! Vec<DocumentChunk> Output
28//! ```
29//!
30//! # Features
31//!
32//! This module is feature-gated behind the `ai` feature flag:
33//!
34//! ```toml
35//! [dependencies]
36//! webfang = { version = "1.0", features = ["ai"] }
37//! ```
38//!
39//! # Model Information
40//!
41//! - **Model**: `sentence-transformers/all-MiniLM-L6-v2`
42//! - **Format**: ONNX (optimized for inference)
43//! - **Size**: ~90MB
44//! - **Max Tokens**: 512 per chunk
45//! - **Cache Location**: hf_hub native cache (`~/.cache/huggingface/hub`)
46//!
47//! # Rust-Skills Applied
48//!
49//! - `async-join-parallel`: Concurrent embedding generation
50//! - `mem-reuse-collections`: Buffer reuse
51//! - `own-borrow-over-clone`: Borrow over clone
52//! - `async-spawn-blocking`: CPU-intensive inference
53//! - `opt-simd-portable`: SIMD cosine similarity
54//!
55//! # Examples
56//!
57//! ```no_run
58//! # async fn example() -> anyhow::Result<()> {
59//! use webfang_ai::{SemanticCleaner, SemanticCleanerImpl, ModelConfig};
60//!
61//! let config = ModelConfig::default();
62//! let cleaner = SemanticCleanerImpl::new(config).await?;
63//!
64//! let html = "<article><p>Hello World</p></article>";
65//! let chunks = cleaner.clean(html).await?;
66//!
67//! println!("Generated {} chunks", chunks.len());
68//! # Ok(())
69//! # }
70//! ```
