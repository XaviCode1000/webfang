Vault-search AI port wiring (#433) — only compiled with the ai feature. AI port wiring for the MCP server (#433).

Constructs the concrete vault-search ports — the ONNX embedding adapter and the Markdown chunker — behind the ai feature and injects them into the Container. The SQLite note repository is wired ONLY when the consumer explicitly enables the persistence feature (--features ai,persistence), keeping the ai feature free of database dependencies.

Mirrors the semantic-cleaner wiring precedent in examples/mcp_server.rs: construction failures degrade gracefully (a warning is logged and the server keeps running) so the affected tools answer with honest feature-gated errors instead of the server failing to boot.

When persistence is enabled, the note repository reuses the elastic pipeline’s SQLite database (resolved via resolve_db_path / env_db_path, default ~/.webfang/crawl.db, overridable with WEBFANG_DB_PATH). The frozen schema already carries the notes and note_chunks tables alongside the elastic chunks table, so one database serves both pipelines.
