Granite-97M based semantic inspector for Tier 2 selector repair.

Implements SemanticInspectorPort using the existing InferencePool for ONNX inference and MiniLmTokenizer for tokenization. Embeddings are compared via cosine similarity to find the best matching CSS selector.
