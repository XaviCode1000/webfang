Batch processing module — Planner-Worker pattern for parallel crawl execution

This module provides batch processing capabilities for crawling multiple URLs concurrently with progress tracking and graceful shutdown.

§Architecture

BatchJob (input)
    ↓
BatchProcessor (worker pool with semaphore)
    ↓
BatchResult (output)

The BatchProcessor wraps the existing crawl_site() function to process multiple URLs concurrently while respecting concurrency limits via [tokio::sync::Semaphore].
