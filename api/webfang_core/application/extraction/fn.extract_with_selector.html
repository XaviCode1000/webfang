pub fn extract_with_selector(

    inspector: Option<&dyn DomInspectorPort>,

Expand description

Extract HTML content using a CSS selector.

When selector is not “body”, parses the HTML and extracts all elements matching the selector. Returns the outer HTML of matched elements wrapped in a <div> for Readability processing. If no elements match or the selector is invalid, returns ExtractResult::Fallback with the full HTML and an optional diagnostic (when an inspector is provided).

§Arguments

  • html - The HTML document to extract from
  • selector - CSS selector string (use "body" to skip extraction)
  • inspector - Optional DOM inspector for diagnostics on failure paths
