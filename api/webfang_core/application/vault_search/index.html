Vault search service — semantic search over Obsidian vault notes (#386).

Orchestrates the search pipeline: load indexed vectors → embed query → rank by cosine similarity → return top-N results. Also provides note indexing: chunk markdown → embed chunks → persist to NoteRepository.

§Architecture

Concrete application struct (following the ElasticIngestion pattern). Injects domain ports (EmbeddingPort, NoteRepository, TextChunker) — no dependency on webfang_ai concrete types.
