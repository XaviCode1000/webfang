Discovery module — URL discovery and single-URL scraping

Functions for discovering URLs from websites (DOM link extraction) and the TUI single-URL scraping use case. Part of the TUI workflow: discover → select → scrape. Sitemap crawling lives in sitemap_discovery.rs and sitemap XML parsing in the infrastructure layer (issue #442); both are re-exported here so existing import paths keep resolving.
