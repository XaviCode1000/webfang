Adaptive CSS selector repair engine — 2-tier cascade with caching.

Tier 1 (lexical, Jaro-Winkler) runs synchronously via DomInspectorPort. Tier 2 (semantic, embeddings) runs asynchronously via SemanticInspectorPort only when Tier 1 confidence is ambiguous (0.70–0.85). A [DashMap] cache with TTL prevents redundant inference calls.
