Application-layer implementation of the domain HTTP port.

The port contract (HttpClientPort, HttpResponse) is defined in the domain layer (crate::domain::http_port). This module provides the production impl HttpClientPort for wreq::Client and the mock test double, depending inward on the domain trait.
