Module downloader

Source
Expand description

Downloader abstraction for page fetching.

Provides the Downloader trait and supporting types for fetching pages. Implementations handle HTTP requests, cookie extraction, and connection pooling.

§Architecture

This module follows Clean Architecture: the trait defines the contract, and concrete implementations (like WreqDownloader) live in the same module but are swapped via dependency injection.
