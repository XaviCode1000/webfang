pub fn read_vault_notes(
    vault_path: &Path,

Expand description

Read all Markdown notes from an Obsidian vault.

Walks the vault directory recursively, collecting every .md file while skipping hidden directories (names starting with .). Symlinks are followed (Obsidian uses them for template folders).

§Arguments

  • vault_path — Root directory of the vault (should contain .obsidian/)

§Returns

A vector of VaultNote for every .md file found. An empty vault returns Ok(vec![]).

§Errors

Returns ScraperError::Io if the vault directory cannot be read or filesystem metadata is unavailable.
