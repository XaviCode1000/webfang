pub fn init_json_logging(
    level: &str,
    log_dir: Option<&Path>,
    app_name: &str,

Expand description

Initialize JSON logging with file rotation.

§Arguments

  • level - Log level: “error”, “warn”, “info”, “debug”, “trace”
  • log_dir - Optional directory for log files. If None, logs to stderr only.
  • app_name - Application name for log file naming (default: “webfang”)

§Returns

Ok(LogGuard) on success - keep this guard alive until program exit. The guard ensures all logs are flushed when dropped.

§Example

ⓘ
fn main() {
    let _guard = init_json_logging("info", Some("/var/log"), "myapp").unwrap();
    // ... application runs ...
    // Logs are flushed when _guard is dropped at end of main
}
