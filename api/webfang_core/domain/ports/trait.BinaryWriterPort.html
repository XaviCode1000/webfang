Expand description

Port trait for writing binary payloads (PDFs, images, archives) to disk.

Abstracts filesystem persistence so application use cases never call std::fs directly — Clean Architecture keeps the application layer free of filesystem specifics (issue #442). The production adapter FsBinaryWriter creates the parent directory tree and writes the bytes; tests inject a temp-dir or in-memory implementation.
