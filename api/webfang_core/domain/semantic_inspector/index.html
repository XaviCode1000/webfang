Semantic inspector port — async domain trait for Tier 2 selector repair.

Defines the contract for semantic (embedding-based) CSS selector matching. Concrete implementations live in the webfang_ai crate’s infrastructure layer. The trait uses BoxFuture for dyn-compatibility, matching the pattern established in super::repository::VectorRepository.
