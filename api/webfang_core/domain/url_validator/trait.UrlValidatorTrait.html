Expand description

Trait for URL validation logic.

Domain defines the contract; infrastructure provides HTTP-aware implementations while the domain itself provides a pure, stateless implementation (StaticUrlValidator) suitable for tests.

Uses native impl Future return position in trait (Rust 1.88+), no async-trait crate needed.
